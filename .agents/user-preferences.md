# User Preferences

- **Bahasa:** Bahasa Indonesia untuk seluruh interaksi chat dan dokumentasi proyek.
- **Arsitektur:** Clean Architecture, modular Go, production-grade, tanpa hardcode data pribadi.
- **UI/UX:** DaisyUI + Tailwind (Dark Mode / Night theme), HTMX untuk interaktivitas dinamis, responsive, informatif.
- **Reliability:** Anti-ban rate limiting, message queue dengan retry, graceful shutdown, health check.
