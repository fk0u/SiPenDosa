Versi asli & jiwa mahasiswa

Lahir dari realita rasa sungkan

Mengingatkan dosen berkali-kali tentang kepastian jadwal kuliah, ruangan, atau kelas pengganti kadang terasa seperti "berdosa" bagi mahasiswa.

Takut dianggap tidak sopan, takut dinilai mengganggu waktu istirahat dosen, atau takut dicap tidak mandiri. Tapi di sisi lain, mahasiswa butuh kepastian agar tidak menunggu berjam-jam di depan ruang kelas kosong tanpa kabar.

"Maka lahirlah SiPenDosa: Sebuah asisten cerdas yang rela menanggung beban 'dosa' sungkan tersebut—mengirimkan pengingat dengan etika bahasa santun, terjadwal rapi pada H-1, sehingga mahasiswanya tidak perlu cemas lagi."
Versi formal (SRS / dokumentasi)

Sistem Pengingat Dosen Saatnya

Untuk keperluan administrasi, proposal, dan Software Requirements Specification (SRS), SiPenDosa didefinisikan secara resmi sebagai Sistem Pengingat Dosen Saatnya.

Sistem otomasi berbasis Golang yang mengirimkan notifikasi konfirmasi perkuliahan terjadwal kepada dosen pengampu secara mandiri melalui protokol WhatsApp Web Multi-Device.

SiPenDosa = S-I-P-E-N-D-O-S-A

Arsitektur rekayasa sistem

Dirancang untuk keandalan maksimal di server mandiri (VPS) dengan konsumsi RAM di bawah 50 MB.

Golang core
Daemon statis berkecepatan tinggi tanpa runtime VM.
Zero-CGO SQLite
modernc.org/sqlite WAL isolated database.
whatsmeow engine
WhatsApp Multi-Device dengan typing presence.
HTMX + WebSocket
Interaktivitas reaktif tanpa bloated client JS.
