⚡ 1-Klik Automatic Update & OTA Engine

Kini aplikasi secara otomatis mendeteksi ketersediaan rilis terbaru di GitHub dan memungkinkan pemasangan langsung dalam 1 klik tanpa unduh manual di browser:

  • Android Package Installer Direct Hook: Mengunduh biner APK langsung ke penyimpanan aplikasi dan membuka layar pembaruan native Android via ApkFileProvider.
  • Self-Update Desktop & Server: Mendukung hot replacement binary untuk distribusi Linux, macOS CLI, Windows, dan skrip Termux.
  • Indikator Pembaruan Real-Time: Pulsing header badge dan kartu pembaruan sistem di halaman pengaturan.
📱 Pengalaman Antarmuka Mobile App 100% Native

Peningkatan total pada sisi aplikasi Android agar terasa sepenuhnya seperti aplikasi mobile modern:

  • Pembersihan Developer Top Bar: Menghapus tombol debug kasar yang memenuhi layar; digantikan dengan tampilan layar penuh yang bersih dan elegan.
  • Native Splash Loader: Tampilan pembuka yang mulus dengan ikon SiPenDosa yang berpendar dan transisi fade-in saat server siap.
  • Immersive Status & Navigation Bar: Penyelarasan warna status bar dan bilah navigasi Android ke nuansa Obsidian (#08090d).
  • Thumb-Friendly Bottom Bar: Navigasi bawah 5 tab dengan haptic touch feedback dan padding aman (safe-area-inset).
🛠️ Perbaikan Bug & Optimasi Template
  • Memperbaiki error refleksi template Go: can't evaluate field ActiveSchedules in type interface {} pada halaman dashboard.
  • Penambahan fallback bertingkat pada seluruh elemen statistik antarmuka.
  • Peningkatan kestabilan D8 Dalvik compiler untuk Android SDK 33+.
