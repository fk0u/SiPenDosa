v1.2.0 Versi terpasang

SiPenDosa v1.2.0

Rilis resmi: 09 September 2026
GitHub ↗
👥 Dynamic WhatsApp group & contact picker (Issue #2)

Otomatis memuat daftar grup WhatsApp dan kontak yang terhubung pada bot melalui WhatsMeow. Dilengkapi dropdown pemilih interaktif pada pembuatan jadwal sehingga pengguna tidak perlu lagi menyalin JID grup secara manual.

🌐 Zero-config public tunneling (Issue #3)

Akses global remote instan via Cloudflare Quick Tunnel dengan tombol 1-klik di menu Pengaturan. Dilengkapi live status endpoint dan QR Code instan untuk membuka dashboard dari HP di jaringan internet mana pun tanpa port-forwarding.

📅 Papan jadwal publik & sinkronisasi kalender (Issue #4)

Portal jadwal perkuliahan publik di /jadwal untuk mahasiswa tanpa login. Dilengkapi hitung mundur perkuliahan, filter hari, pencarian dosen/matkul, serta ekspor file .ics untuk Google Calendar & Apple Calendar.

🔐 Autentikasi dua faktor (2FA / TOTP) & multi-tenant session

Penguatan keamanan akun menggunakan TOTP Authenticator (Google Authenticator / 1Password) dengan kode pemulihan darurat, registrasi terkontrol oleh Admin, serta isolasi data kontak, jadwal, antrian, dan multi-sesi WhatsApp per pengguna.

⚡ Perbaikan krusial WhatsApp WebSocket di Android

Memperbaiki kegagalan resolusi DNS saat engine WhatsApp menghubungkan WebSocket ke server WhatsApp Web di Android melalui DNS Fallback Resolver mandiri, sinkronisasi thread-safe write mutex pada Gorilla WebSocket Hub, serta pemuatan bundel sertifikat Root CA Android.

📱 Penyempurnaan UI mobile (single bottom dock bar)

Menghilangkan masalah bilah dock ganda (double bottom dock) dengan menghapus dock native Android dan mempertahankan dock bar responsif Web UI SiPenDosa yang elegan, ergonomis, dan berfitur lengkap.

🛡️ Client realtime tangguh & polling fallback

Bootstrapping client JavaScript diperbaiki agar langsung terhubung pada WebView Android, dilengkapi sistem HTTP Polling Fallback otomatis saat WebSocket terputus sehingga status WhatsApp dan QR Code selalu tampil real-time.

v1.1.1 Rilis sebelumnya

SiPenDosa v1.1.1

Rilis resmi: 07 September 2026
GitHub ↗
⚡ 1-klik automatic update & OTA engine

Kini aplikasi secara otomatis mendeteksi ketersediaan rilis terbaru di GitHub dan memungkinkan pemasangan langsung dalam 1 klik tanpa unduh manual di browser:

  • Android Package Installer Direct Hook: Mengunduh biner APK langsung ke penyimpanan aplikasi dan membuka layar pembaruan native Android via ApkFileProvider.
  • Self-update desktop & server: Mendukung hot replacement binary untuk distribusi Linux, macOS CLI, Windows, dan skrip Termux.
  • Indikator pembaruan real-time: Pulsing header badge dan kartu pembaruan sistem di halaman pengaturan.
📱 Pengalaman antarmuka mobile app 100% native

Peningkatan total pada sisi aplikasi Android agar terasa sepenuhnya seperti aplikasi mobile modern:

  • Pembersihan developer top bar: Menghapus tombol debug kasar yang memenuhi layar; digantikan dengan tampilan layar penuh yang bersih dan elegan.
  • Native splash loader: Tampilan pembuka yang mulus dengan ikon SiPenDosa yang berpendar dan transisi fade-in saat server siap.
  • Immersive status & navigation bar: Penyelarasan warna status bar dan bilah navigasi Android ke nuansa Obsidian (#08090d).
  • Thumb-friendly bottom bar: Navigasi bawah 5 tab dengan haptic touch feedback dan padding aman (safe-area-inset).
🛠️ Perbaikan bug & optimasi template
  • Memperbaiki error refleksi template Go: can't evaluate field ActiveSchedules in type interface {} pada halaman dashboard.
  • Penambahan fallback bertingkat pada seluruh elemen statistik antarmuka.
  • Peningkatan kestabilan D8 Dalvik compiler untuk Android SDK 33+.

🔢 WhatsApp pairing code (tautkan nomor HP)

Solusi login WhatsApp tanpa perlu memindai QR code via kamera: cukup masukkan nomor WhatsApp Anda dan terima 8 karakter kode pairing langsung di aplikasi.

🛡️ Pengerasan keamanan OWASP Top 10

Validasi CSRF Origin Header pada seluruh mutasi data, perlindungan BFLA pada rute administratif, rate limiter login 10 req/menit, dan pembatasan body payload proteksi DoS.

📱 Ekosistem Termux & web terminal

Penyediaan CLI tool sipen pair <nomor> dan antarmuka konsol shell mandiri pada rute /terminal.
