Pesan Interaktif & Bot Otomatis

Format WhatsApp API Resmi & Auto-Reply Cerdas

1
Tombol Interaktif (NativeFlow Buttons):

Pesan yang dikirimkan ke dosen dilengkapi dengan tombol pilihan cepat: [Hadir Offline], [Hadir Online], dan [Minta Jadwal Ulang].

2
Chatbot Asisten Dosen Otomatis:

Ketika dosen menekan tombol atau membalas angka 1, 2, atau 3, bot SiPenDosa langsung membalas santun secara otomatis dan memperbarui status kehadiran di antrian pesan.

3
Fallback Teks Terstruktur:

Pada perangkat WhatsApp versi lama yang belum mendukung rendering NativeFlow Buttons, sistem secara otomatis mengalirkan menu interaktif berbasis teks dengan opsi balasan angka.

Efisiensi Server & Proteksi Smart

Didesain untuk VPS Kecil (RAM 256MB - 512MB)

Hemat RAM (Client Hibernation):

Socket WhatsApp masuk mode tidur (hibernasi) otomatis setelah 15 menit tanpa aktivitas pengiriman, menjaga pemakaian RAM server tetap di bawah 35MB.

Smart Rate Limiting (Non-IP):

Pendaftaran publik terbuka dilindungi oleh device fingerprint & entropy timing, bukan pemblokiran IP. Seluruh mahasiswa dalam WiFi/NAT kampus yang sama tetap bisa mendaftar tanpa terkena 429 Too Many Requests.

SQLite WAL Mode & Auto-Prune:

Database SQLite dikonfigurasi dengan Write-Ahead Logging (WAL) dan sinkronisasi normal untuk konkurensi tinggi tanpa lock timeout, dilengkapi pembersihan log lawas otomatis.
